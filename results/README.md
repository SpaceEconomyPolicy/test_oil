# results/

Эта папка предназначена для сохранённых проектов, выгрузок и сравнений команды. В стартовом репозитории нет заранее рассчитанного «правильного» плана: он неизбежно заякорил бы решения участников.

Веб-интерфейс умеет выгружать полный проект в JSON и расчёт в XLSX. Команда может положить свои финальные файлы сюда перед сдачей.
