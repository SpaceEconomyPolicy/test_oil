# Методика расчёта

## Материальный баланс

На помесячном шаге: `inventory_end = min(capacity, inventory_start + gross_arrival - loss) - served`.

Потери считаются один раз от валового поступления. Если перед обслуживанием спроса расчётный запас превышает ёмкость, лишний объём фиксируется как `capacity_overflow_t` и одновременно создаёт нарушение; он не исчезает молча.

Критический спрос входит в общий. Сначала обслуживается критическая часть, затем некритическая. Физический запас отрицательным не становится: неудовлетворённый объём идёт в `shortage`.

## Сроки и мощности

Для A/B при использовании канала требуется `order_date`. Срок проверяется до первого дня `first_delivery_month`. Мощность и резерв для неполного года пропорциональны числу активных дней из 365.

C доступен только после оплаты опциона и exercise CAPEX с учётом выбранного lead time. D доступен с 2038 года только при финансировании полного case CAPEX до конца 2037 года. Любой добавленный исследовательский источник подчиняется `available_from`.

## Платежи

Для канала за период:

`paid_quantity = max(planned_delivery, take_or_pay_share * reserved_capacity * active_fraction)`

`variable_payment = variable_price * paid_quantity`

`reservation_payment = reservation_fee * reserved_capacity * active_fraction`

CAPEX, fixed OPEX и holding cost добавляются отдельно. Holding cost рассчитывается по среднему физическому запасу каждого месяца. Дисконтирование идёт к 2035 году по выбранной реальной ставке.

## Резерв

`reserve_required = annual_total_demand * 45 / 365`.

Физический вариант проверяется по запасу на начало года. Контрактный вариант требует достаточного зарезервированного Emergency и `bridge_coverage` на 42 дня до его прибытия. Годовая мощность 80 т сама по себе не считается запасом.

## Сценарии

Standard использует базовый спрос и цены. Low/high меняют общий спрос и сохраняют долю критического спроса базового года. Mandatory stress одновременно применяет заданные организатором изменения и не добавляет к ним скрытые шоки.

Monte Carlo вынесен в отдельный исследовательский экран. Там коэффициент reliability интерпретируется как годовая Bernoulli-доступность канала. Это сценарная математическая интерпретация, а не статистически подтверждённый прогноз вероятности отказа.
