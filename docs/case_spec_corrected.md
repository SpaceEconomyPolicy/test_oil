# Уточнённая постановка для реализации

Цель команды: спроектировать снабжение орбитального топливного узла на 2035–2040 годы, сочетая долгосрочные, гибкие, аварийные и перспективные лунные источники. Решение должно показать, какие обязательства принимаются заранее, какие решения остаются опционами и как меняется план при стрессах.

Минимальный цифровой контур должен связывать спрос, резервирование, даты заказа, ввод мощностей, поставки, хранение, потери, service level, CAPEX/OPEX, take-or-pay, резерв, риски и выгрузку. Все нарушения показываются численно. Исходные параметры standard и mandatory stress не меняются скрыто.

Свободная часть решения: алгоритм выбора стратегии, MCDA/robust/real-options надстройка, дополнительные риски, договорные механизмы, исследовательские источники и расширение горизонта. Эти расширения отделяются от контрольного расчёта.
